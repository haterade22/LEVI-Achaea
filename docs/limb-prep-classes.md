# Limb-Based Offense Systems — Per-Class Reference

Quick reference for all LEVI offense systems that use limb damage as a kill route.

---

## Tekura 6-Limb Backbreaker (TK6)

**Namespace:** `tekura6`
**File:** `tekura/002_Tekura_6Limb_Offense.lua`
**Kill Route:** Prep all 6 limbs → Break arms+torso → Break legs → Backbreaker

### Phases

| Phase | Action | Command |
|-------|--------|---------|
| PREP | Build all 6 limbs to ~86% without breaking any | `combo <tar> <kick> <punch1> <punch2>` |
| BREAK_UPPER | Break both arms + torso, switch to Horse stance | `combo <tar> mnk <arm> spp <arm> hkp;hrs` |
| BREAK_LOWER | Wrench torso (prones) + break both legs, switch to Bear | `combo <tar> wrt torso hfp left hfp right;brs` |
| KILL | Backbreaker | `bbt <tar>` |

### Limb Targeting Strategy

- **Prep threshold:** `100 - punchDamage` (dynamic, typically ~86%)
- **Damage tracking:** `lb[target].hits[limb]` (Romaen's counter)
- **Break prevention:** `findSafeLimb()` with simulated damage across all 3 attacks in a combo
- **Right-limb tiebreaker:** When damage is equal, prefers right limbs (left preps first → heals first on restoration)
- **Parry handling:** 4-pass priority (non-parried unprepped → parried unprepped → overflow → parried overflow)
- **Parry bypass:** When last unprepped limb is parried: sweep (prones, disables parry) + punch

### Key Config

```lua
tekura6.config.breakThreshold = 100
tekura6.config.kaiMode = "surge" -- or "cripple"
tekura6.state.kickDamage = 25    -- dynamic from combat
tekura6.state.punchDamage = 14   -- dynamic from combat
```

## Infernal DWC Vivisect (4-Limb)

**Namespace:** `infernalDWC`
**File:** `dwc/001_Infernal_DWC_Vivisect.lua`
**Kill Route:** Prep arms + focus leg → Undercut leg → DSL arm with epteth/epseth → Vivisect

### Phases

| Phase | Action | Entry Condition |
|-------|--------|-----------------|
| DAMAGE KILL | Quash + Arc | Health ≤ 40% |
| KILL | Vivisect | All 4 limbs Level 1+ |
| EXECUTE | Undercut + DSL | Both arms + focus leg at 90%+ |
| PREP | Build limb damage | Default |
| RIFTLOCK | Counter to RESTORE | Manual entry |

### Execute Sequence

```
Step 0: UNDERCUT left leg (battleaxe)
  → Breaks leg (L2) + 4s salve lock + prone

Step 1: DSL right arm epteth epseth (scimitars)
  → Breaks right arm (L2)
  → Epteth gives left arm L1
  → Epseth gives right leg L1
  → All 4 limbs at L1+ → VIVISECT
```

### Key Mechanics

- **Epteth/epseth venoms:** Give Level 1 breaks to NON-TARGETED limbs
- **4s salve lock:** From undercut, prevents mending during execute window
- **Left-first restoration:** Irrelevant during execute due to salve lock
- **RESTORE counter:** Detects RESTORE ability, pivots to RIFTLOCK (affliction lock)

### Key Config

```lua
infernalDWC.config.prepThreshold = 90
infernalDWC.config.breakThreshold = 100
infernalDWC.config.focusLeg = "left"
```

## DWB-Runie (Runewarden)

**Namespace:** `dwbRunie`
**File:** `dwb_runie/001_DWB_Runie_Logic.lua`
**Kill Route:** Prep limbs → Break with expend/doublewhirl → Bisect or Pulp

### Modes

| Mode | Kill Method | Break Targets |
|------|------------|---------------|
| Torso | Bisect (low HP) | Right leg → Left leg + Torso |
| Pulp | Skull fractures → Pulp | Right leg → Left leg + Head |
| Group | Party coordination | Flexible |

### Key Mechanics

- **Right leg first:** Always breaks right leg first with expend (instant prone), exploiting left-first restoration
- **Momentum system:** Expend costs momentum, generated by doublewhirl
- **Prep threshold:** 99.9% (single whirl = break)
- **Restoration awareness:** If torso restored but legs still broken → auto-pivots to skull fractures

### Key Config

```lua
dwbRunie.config.prepThreshold = 99.9
dwbRunie.config.breakThreshold = 100
dwbRunie.config.bisectThreshold = 34  -- health % for bisect finish
```

## Blademaster

**Tracking:** `ataxiaTables.limbData` + `tLimbs`
**File:** `limb_management/002_Blademaster_Limbcounting.lua`

### Key Mechanics

- **Compass slash prediction:** `ataxia_blademasterNeedComp()` simulates 10 alternating hits to predict if left would break before right
- **Stance modifiers:** Sanya (1.06x), Arash (1.16x), Thyr (0.85x), Mir (0.95x)
- **Break threshold:** > 99.99%

### Blademaster Ice Strategy

**File:** `blademaster/005_CC_BM_Ice.lua`

Always targets **RIGHT leg** for breaks ("curing applies left first, so right stays broken longer"). This is the canonical example of left-first exploitation in the codebase.

## Apostate Vivisect

**Namespace:** `apostate`
**File:** `apostate/015_CC_Apostate.lua`
**Kill Route:** Truelock → Shrivel all 4 limbs → Vivisect

### Shrivel Rotation

```
Right arm → Left arm → Right leg → Left leg
```

- **No damage tracking:** Uses V3 affliction system (`haveAff("brokenleftarm")` etc.)
- **No break prevention:** Shrivels are the break mechanism, not a side effect
- **No restoration awareness:** Blindly cycles through rotation; re-shrivels if target restores

## Shikudo Dispatch

**Namespace:** `shikudo`
**File:** `shikudo/010_Shikudo_Offense.lua` (unified)
**Kill Route:** Prep legs + head → Gaital → Sweep + break → Needle (windpipe) → Dispatch

### Phase Progression

```
Willow (head prep) → Rain (leg prep, 24 kata) → Oak (head finish) → Gaital (kill)
```

### Key Mechanics

- **Leg protection:** NEVER break legs until head is also prepped
- **LIGHT modifier:** Reduces staff damage to avoid premature breaks on prepped limbs
- **Hyperfocus:** Bypasses parry on focused limb at cost of half damage (always head)
- **Spinkick:** Standing = torso; Prone = head; Prone + damaged head = instant mangle!
- **Dynamic thresholds:** `100 - kuro_damage` for legs, `100 - form_attack_damage` for head
- **Form transitions:** Require 5+ kata, inline with combo command

### Kill Conditions

```
tAffs.prone
AND (left_leg >= 100 OR right_leg >= 100)
AND (head >= 100 OR tAffs.damagedhead)
AND (tAffs.damagedwindpipe OR tAffs.crushedthroat)
→ DISPATCH
```

## Shared Tracking Infrastructure

### tLimbs (Global Table)

```lua
tLimbs = { H=0, T=0, LA=0, RA=0, LL=0, RL=0, BP=100, staff=15, airstrike=8 }
```

- Reset via `magi_resetLimbs()` or on target change
- 180-second auto-decay timers per limb (`targetLimbs_updateTimers()`)

### lb[target].hits (Romaen's Counter)

```lua
lb[target].hits = { head=0, torso=0, ["left arm"]=0, ["right arm"]=0, ["left leg"]=0, ["right leg"]=0 }
```

- Event-driven: `raiseEvent("limb hits updated", name, limb, amount)`
- 180-second auto-decay timers per limb
- `lb.salve()` handles restoration detection with 4.0s timer

### Common Break Detection

```lua
function target_limbBroke(limb)  -- Called by all tLimbs-based systems
```

### Common Restoration Detection

```lua
function target_appliedTo(where) -- "arms" or "legs"
function target_curedLimb(limb)  -- State change handler
function target_salveBal(num)    -- Salve balance tracking
```
